ATMOS ATLAS — MAPLIBRE EDITION

Static website: no build command, dependencies to install, API keys, or environment variables. Unzip and deploy the folder containing index.html. Select Other for the Vercel framework, leave the build command blank, and use . as output directory if required.

MapLibre GL JS renders the map with OpenFreeMap vector basemaps. Open-Meteo supplies forecasts and city search, RainViewer supplies recent radar, and NASA EONET supplies reported wildfire events. Attribution is displayed on the page. Internet access is required. Geolocation needs HTTPS and permission; the map needs WebGL. External services can have coverage gaps and outages. Temperature and wind layers are model samples, not continuous heatmaps. Fire reports are not comprehensive emergency alerts.
